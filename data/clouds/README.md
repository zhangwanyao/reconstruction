# data/clouds —— 8 份带参考模型的点云

随仓库分发的**真实测试集**：8 份自上而下线扫点云，每份都带一个参考 STEP 模型（评分基准）。
所有文件都是 `FIELDS x y z`、float32、`COUNT 1`、`VIEWPOINT 0 0 0 1 0 0 0`，**传感器 +Z 指向相机（朝上）**，单位 mm。

## 1. 清单与来源

| 短名 | 原文件名（不含扩展名） | 点数 | 来源 | PCD 存储 |

| F168 | 现场包_20261026_101859_168 | 367,188 | 现场线扫 | binary |
| F173 | 现场包_20261030_090521_173 | 1,937,989 | 现场线扫 | binary |
| F455 | 现场包_20261029_142909_455 | 3,011,118 | 现场线扫 | binary |
| WP | workpiece | 1,829,111 | 现场线扫 | binary |
| WP169 | workpiece_cloud169 | 1,689,439 | 现场线扫 | binary |
| WP338 | workpiece_cloud338 | 807,346 | 现场线扫 | binary |
| SS30 | SS30_00001_panel_grid_ribs | 1,574,054 | 仿真 | binary |
| SS34 | SS34_00001_planar_truss | 3,084,513 | 仿真 | binary_compressed（LZF） |

- 原始数据在 `E:\_整理_分类\02_工程数据与点云\建筑钢结构_test\pcd_sim\pcd\`（8 对 `.pcd` / `.step`），复制时改成了短名（中文路径会让部分工具出错）。
- **SS34u.pcd** 是 SS34 的未压缩版，**只给评分程序用**（Python 解 LZF 压缩较慢）；重建程序必须能直接读压缩的 `SS34.pcd`（`tools/read_any_pcd.py` 支持）。
- 点云特点：现场云只能扫到朝上的面和立板顶部窄条，有飞点、混合像素；仿真云底面也有点（能直接量出底板厚度）、SS30 点稀（俯视每 mm² 只有 0.47 个点）。

| WP169 | 底板 t20 + 5 块立板（#2 倾 4.4°、#5 倾 8.3°）+ 斜板 #6（倾 19.6°，t12.1，长 369）+ 带 4 孔水平板 #7（t15.7） |

## 3. 用法

```powershell
# 单份
python -I tools/recon.py data/clouds/F168.pcd out/F168

# 全流程基准（跑 8 份 → check_step → eval_recon → 对照分数线 → 写 summary.md）
python -I tools/run_bench.py `
  --cmd "<python.exe路径> -I tools/proto_v2.py {pcd} {out}" `
  --data data/clouds --ocp <OCP 所在目录> --out out/bench `
  --eval-cloud SS34=data/clouds/SS34u.pcd --repeat F168 --time-limit 0
```
