# 06 第 5 步：沿轴线逐段切片，量出每块板

> 读完这一章，你应该能回答：一段"看着像板"的骨架段，是怎么变成一块"有准数"的板的？板厚、方向、中线和端点分别是怎么量出来的？
> 代码位置：`tools/proto_v2.py` 第 196–264 行。

## 1. 这一步要解决什么问题

第 4 步给的是**骨架段**：方向大概对（有 ±1° 的像素锯齿误差）、宽度是从骨架的距离变换估的（只准到几毫米）。直接拿它建模，长板一端会偏出好几毫米，板厚也差 10% 以上。

这一步把每段沿轴线**每 5 mm 横切一刀**，在每个切片里量三个数，再用整条板的几十上百个切片取统计值。单个切片里的遮挡、飞点、混合像素影响不了结果——这就是整套方法最核心的一招。

每个切片量什么：

| 量 | 怎么量 | 变成什么 |
|---|---|---|
| 顶高 | 切片内所有点 z 的 P95 | 顶边剖面 `bins` 的原始数据 |
| 顶面条带左右边 | 顶高 4 mm 以内的点，v 坐标的 P2.5 / P97.5 | 板厚、中线位置 |
| 切片中心 | 左右边的中点 | 直线的稳健拟合 → 方向、中线 |

## 2. 取点：不是整个矩形，而是一串圆

```python
def strip_points(c, d, s0, s1, half):      # proto_v2.py 第 201–205 行
    n = max(1, int(np.ceil((s1 - s0) / max(2 * half, 40.0))))
    ss = s0 + (np.arange(n) + 0.5) * (s1 - s0) / n
    lists = tree2.query_ball_point(c[None] + ss[:, None] * d[None], np.hypot((s1 - s0) / n / 2, half))
    return np.unique(np.concatenate([np.asarray(l, np.int64) for l in lists]))
```

注意是**一串圆**，不是矩形 `[s0, s1] × [−half, half]`：两端各多包一点。第 8 步判倾斜板的板长依赖这个细节，照原样实现，别改成矩形。

参数：

- `half = w / 2 + 6`：横向放宽 6 mm，因为骨架估的宽度不准，放宽了才切得全；
- `ext = max(15, 0.5w + 5)`：两端各外延，让端点附近的切片有足够的点；
- 少于 30 个点就放弃这段（太短、太孤的段不要）。

高度下限 `hlo`：

- 有底板：`h_min / 2`（= 4 mm），把底板上的点排掉；
- 无底板：不限制；
- 段带 `level`（从宽区来的）：再取 `max(hlo, level − 15)`，只看本层附近，别把别的层的点算进来。

## 3. 迭代：先粗后细，最多 3 轮

```python
for it in range(3):                         # proto_v2.py 第 220 行
```

每一轮：

1. 把点投到板坐标：`s = (xy − c)·d`（沿板方向），`v = (xy − c)·nrm`（横向）。
2. **band** = `|v| < half` 且 `s0 − ext < s < s1 + ext`；**sel** = band 且 `z > hlo`。sel 少于 30 个就失败。
3. **切片**：`b = ⌊(s − smin)/5⌋`，每片顶高 = 片内 z 的 **P95**（比最大值抗飞点）。点数不到 3 的片记空。
4. 空片的顶高**线性插值**补上（`topi`）。
5. **顶面条带** cap = 片内 `z > topi[b] − 4` 的点（离本片顶高 4 mm 以内）。只在这些点里量宽度——立板侧面上被斜着扫到的点不会把宽度撑大。
6. 每片在 cap 点里取 v 的 **P2.5** 作左边、**P97.5** 作右边（少于 6 个点的片记空）。中点 `C = (lo + hi)/2`。
7. 对有效的切片拟合直线 `C = a + k·S`，**稳健**做法（防个别坏片带偏）：

```python
keep = 全真
重复 3 次:  (a, k) = 用 keep 的切片做最小二乘
            r = C − (a + k·S)
            keep = |r| < 3·(1.4826·median(|r[keep]|) + 0.3)   # median 用更新前的 keep
```

8. 结束迭代的条件：已经是第 3 轮 / 有效片 < 6 / 斜率 |k| > tan 5° / |k| < 1e-4。否则用修出来的中线再切一遍：

```python
c = c + nrm·a;  d = normalize(d + k·nrm)
```

为什么要迭代：骨架的方向有误差，第一次切片的中线拟合会量出一个横向偏移 a 和一个斜率 k，把轴线挪正之后切片才真正垂直于板——切得准，量得才准。

## 4. 结果：板的长相定下来了

```python
wid = ((hi - lo) / 0.95)[good][keep]
width = median(wid)                          # 板厚
voff = median(C[keep] − k·S[keep])           # 中线横向修正
c = c + nrm·voff
s0, s1 = P0.3 / P99.7（cap 点的 s）           # 端点：看得到顶面的范围
bottom = 0（有底板）或 band 内 z 的 P1（无底板）
```

几个关键点：

- **为什么除以 0.95**：P2.5~P97.5 只包住 95% 的宽度。顶面上的点近似均匀分布时，这两个分位点离真边缘各有一个固定的比例差，除以 0.95 还原全宽。
- **方向用切片中心的直线拟合，不用骨架方向**：骨架在 1 mm 像素上有 ±1° 的锯齿，400 mm 长的板一端会偏 3.5 mm；切片中心拟合能把方向定到约 0.1°。
- **宽度逐切片量，不在整条板上量**：方向偏 0.5° 时，整条板上量横向宽度会多出 3.5 mm（400 mm × tan 0.5°），逐切片量没有这个问题。
- `bins` 留的是每片的 (切片中心 s, 顶高)，第 8 步画顶边剖面就用它。
- 拟合完丢掉长度 ≤ 15 或厚度 ≤ 2.5 的板（碎渣）。

## 5. 实际看一眼

用探针把 S1（T 形接头）跑到第 5 步为止，`plates` 长这样（`probe_stages.py` 的输出）：

```
  src=thin ang=0.00  L=261.5 w=8.17 ends=(380.1,131.2)-(641.7,131.2) n_slices=53 w_iqr=0.06 top_med=100.4
```

对照 S1 的真相：长板 A 板厚 8、长 500、顶高 100；短板 B 板厚 10、长 176、顶高 80。

- 两块"半截板"各量出 261 mm，厚度 8.15 / 8.17（真 8）——它们是**同一块板被交叉口切开的两段**，第 6 步会并起来（498.6 mm，真 500）。
- 短板的端点只到 127.3（离 A 的中线还有 4 mm），因为它顶在 A 的侧面，顶面被 A 挡掉了一点；第 7 步会用交线把它顶到 135.3，长 175.5（真 176）。
- `w_iqr` 是切片宽度的四分位距：A 只有 0.06 ~ 0.08（切得又平又稳），B 是 0.48（端头附近有遮挡，宽一点）。

再看 S5（稀疏网格，点距 1.5 mm）：

```
  src=thin ang=89.92 L=160.4 w=6.50 ...
  src=thin ang=0.12  L=211.4 w=7.78 ...
```

真厚度是 8 mm，量出来 6.5、7.78——**稀疏点云的系统性偏薄**：最靠边的点平均落在真边缘内侧约半个点距（0.75 mm）处，两边一减就是 1.5 mm，正好是 8 − 6.5。点距越大偏得越多，这是这套方法的已知短板（第 13 章有记录）。不过后面会看到，这个偏差对评分影响不大（误差阈值 3 mm）。
