# 07 第 6–7 步：共线合并，端点靠交线

> 读完这一章，你应该能回答：被挡断的板怎么接回来？为什么有些"缺口"不能并？板的端点为什么不用"点云在哪结束"来定？
> 代码位置：`tools/proto_v2.py` 第 267–310 行（合并）、第 312–338 行（接头）。

## 1. 问题：同一块板，点云里断成几截

上一章 S1 的两块"半截板"其实是同一块长板，被交叉口切开；现场的板还会被别的板挡住、被飞点打缺。这一步把"方向几乎相同、几乎在一条线上、厚度差不多、中间缺口不是真缺口"的段并起来。

合并不是一锤子买卖：反复扫描，每合并一次就**从头再扫**（合并之后 A 变了，可能又能并 C）。

## 2. 四条门槛（`proto_v2.py` 第 281–295 行）

对每对 (A, B)，全部满足才并：

| 条件 | 门槛 | 意思 |
|---|---|---|
| 方向 | `|dA·dB| < cos 4°` 就不并 | 夹角 ≥ 4°，不是同一块板 |
| 横向偏差 | B 两端到 A 中线的距离，较大的 > `max(3, 0.5·max(wA, wB))` 就不并 | 不在一条线上 |
| 厚度 | `max(wA, wB) > 1.8·min(wA, wB) + 2` 就不并 | 厚度差太多 |
| 缺口 | 缺口 > 400 mm 不并；缺口 > 15 mm 且缺口里"看得到底板"的比例 > 0.3 不并 | 见下 |

**缺口里看得到底板 = 真断开了，是两块板；缺口里没数据 = 被挡住了，可以并。** 这是区分"遮挡"和"真缺口"的关键。

`gap_has_base`（第 268–274 行）：在缺口里按像素间距铺一组点（横向取 `−w/2、0、+w/2` 三条），查每个点所在的像素是否"看得到底板"（`base_vis`），取平均。无底板或缺口短于一个像素时直接算 0。

看 S6（两块板中间留了 100 mm 真缺口，另一块板上盖了 100 mm 无数据阴影）的实测：

```
  pair 0-1 off=0.1 gap=102.0 gap_base=0.007   -> 并（阴影：缺口里看不到底板）
  pair 2-3 off=0.0 gap=102.0 gap_base=0.994   -> 不并（真缺口：缺口里全是底板）
```

合并的动作（第 297–299 行）：

```python
A.update(s0=min, s1=max, w=按 n_top 加权的平均厚度, n_top=相加, bottom=取小)
```

合并过的板要**重新拟合**（第 303–308 行）：用合并后的 (c, d, s0, s1, w) 再跑一遍第 5 步的 `fit_strip`，成功就把新结果换上去（s0/s1 取新旧并集）；失败就保留合并结果。S1 合并后重拟合得到 L = 498.6（真 500）。

## 3. 端点接头：和相交的板求交线

板端不靠"点云在哪里结束"来定——板根、交叉处常被挡住，顶面在端头也扫不全。可靠的是几何关系：**两块板的中间面必然相交**，交点就在对方侧面附近，板端应该顶在对方侧面（或伸过对方端头）。

对每块板 A 的两端（先 s0 端、后 s1 端），找搭档 B（第 314–337 行）：

1. B ≠ A，夹角 > 20°。
2. 求交：`nB = perp(dB)`，`den = dA·nB`，交点在 A 上的位置 `sA = ((cB − cA)·nB)/den`，在 B 上的位置 `sB = (cA + dA·sA − cB)·dB`。
3. 要求 sB 落在 `[B.s0 − 10, B.s1 + 10]` 里（交点得在 B 身上）。
4. `off = (wB/2)/|den|`：沿 A 的方向穿过半个 B 厚度的距离。
5. 要求 `|sA − A的这一端| ≤ off + wA/2 + 3`（离端头很近才配对；2026-11 起从 +15 收紧为 +3：避免把"离端头十几毫米的加劲板"误当成端头的归宿。改动前在 36 份生成数据 + 7 合成样例 + 8 份对比数据上做了四组对比实验，唯一变化是 PC11 的长板端长 153.1 → 160.8 mm、召回 +1.9 点，其余全部无变化）。
6. 满足条件的 B 里，取离 A 这一端最近的。

找到了之后分两种情况（第 333–335 行）：

- **顶到近侧面**（T 形接头，或 L 形接头里较短的那块）：交点在 B 的中段（`B.s0 + 12 < sB < B.s1 − 12`），或 B 不比 A 短 → `A端 = sA + sign·off`，端头正好贴着 B 的侧面；
- **伸到外侧面**（L 形接头里较长的那块盖住短板的端头）：`A端 = sA − sign·off`。

`sign`：s1 端取 −1，s0 端取 +1。记一个 `Joint{end, other, s_other, abut}`，供焊缝表用（本原型只记不画）。

S1 的实测：短板的 s0 端从 127.3 顶到 **135.3**，板长 183.4 → **175.5**（真 176）：

```
-- after 7 junctions plates 2
  src=thin ang=90.03 L=175.5 ends=(392.4,135.3)-(392.3,310.8) joints=['s0']
```

4.08 = wA(长板 8.16) / 2 正好是"顶到近侧面"的 off。注意第 2 步丢过一轮"又短又宽"的残渣（长度 < max(15, 2w)），第 7 步最后又丢一轮（长度 < max(10, 0.5w)）。

两个实现要点：

- **就地修改、按顺序处理**：后处理的板看到的是前面已经改过的 s0/s1。顺序不同结果可能不同，要保持和 Python 一样的顺序。
- 没找到搭档的板端保持拟合出来的长度（自由端），`joints` 里没有记录。
