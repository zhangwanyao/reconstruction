## 1. 顶边剖面：bins 去掉交叉区再连成线

第 5 步的 `bins` 是每个切片的顶高。直接连起来就是顶边——但板被别的板穿过的地方，切片量到的是**别人的顶高**，要跳过。

```python
def profile(p):                             # 第 342–369 行
```

1. 取 `bins` 里 s 落在 `(s0 − 5, s1 + 5)` 内的切片。
2. 对每块别的板 q：夹角 < 20° 跳过；q 的中面和 p 的中线交于 sA（在 p 上）、sB（在 q 上）。sB 在 `[q.s0 − 5, q.s1 + 5]` 内时，把 `|s − sA| < hw` 的切片去掉，`hw = (wq/2)/sn + (wp/2)·|dp·dq|/sn + 4`（sn = 两方向夹角的正弦）。
3. 剩不到 2 片就退回第 1 步的结果；还不到 1 片就用全部 bins。
4. 剩下的切片排成 (s, z)，两端在 s0、s1 处**线性插值**（超出范围取端值），中间取 s0 与 s1 之间的切片。
5. 剖面高差 < 6 mm：当作**平顶**，只用 `(s0, median(z))`、`(s1, median(z))` 两个点。否则在 (s, z) 平面里做 Douglas–Peucker 简化（容差 3 mm）。
6. 所有 z 至少 `bottom + 2`。

看 S2 的斜顶板 C（真顶高从 60 线性爬到 140，板身 30° 摆放）：

```
  prof=[[-375.6, 140.1], [122.8, 61.0]]
```

两个端点 140.1 / 61.0，直线剖面，斜顶被完整保留。S1 的平顶板则是 `[[-125.0, 100.4], [373.6, 100.4]]` 这种两点平线。

## 2. 倾斜板：默认竖直，证据够了才斜

默认每块板都按**竖直**建模。只有"看得到的那个侧面"上拟合出一个可靠的斜平面时，才按倾斜板建模。门槛非常严：8 份真实数据里 4 块真倾斜板全部找到，其余 0 误判。

**为什么不用横切片判倾斜**：切片里的顶面条带只有 4 mm 高，看不出倾斜；切片里的侧面点又常常是被斜着扫到的竖直面（混合像素、阴影边）。早期版本试过，出现一堆假倾斜，已放弃。

### 2.1 找侧面平面：`lean_check`（第 404–461 行）

1. 板高 `Hp = 剖面最高点 − bottom`，板长 < 40 或 Hp < 40 不判。
2. `half = w/2 + 6 + min(80, 0.45·Hp)`，往两侧放宽（斜面会伸出去），在 `(s0+5, s1−5)` 范围内取点。
3. 只留下**顶面以下 6 mm、根部以上**的点：`z < zt − 6` 且 `z > zlo`（zt 是剖面在 s 处的高度，zlo = 6 或 bottom+6）。
4. RANSAC 找平面（第 380–401 行）：法向**近水平**（|nz| < sin 30°）且与板轴线**近垂直**（|n·d| < sin 15°），200 次采样，内点容差 1.5 mm，再迭代拟合两次。
5. 六个门槛**全部**满足才算倾斜板：

| 门槛 | 条件 | 防什么 |
|---|---|---|
| 内点数 | `inl ≥ max(300, 15%·cand)` | 小块噪声面 |
| 高度跨度 | `zspan ≥ max(30, 0.5·Hp)` | 贴地小斜面 |
| 平整 | `rms ≤ 1 mm` | 曲面、碎面 |
| 贴顶 | 该面在顶高处离顶面条带中心 ≤ w/2 + 4 | 根部倒角面 |
| 倾角 | `lean ≥ lean_min`（默认 3°） | 微斜不算 |
| 点密度 | `rel_dens ≥ 0.8·sin(lean)` | 被斜着扫到的竖直面 |

最后一条最妙：**朝扫描仪倾斜 θ 的面，单位面积的点数约为水平面的 sin θ 倍**（投影面积缩小）。竖直面被斜着扫到时远低于这个值——实测假倾斜的 rel_dens ≤ 0.07，真倾斜 ≥ 0.11，中间隔着明显鸿沟。`rel_dens = 内点数 / (板长 · 高度跨度) / rho_top`（rho_top = 俯视每 mm² 点数，第 3 步算的）。

### 2.2 倾斜板怎么建模

```python
t = max(0.5·w, (w − 4·tan θ)·cos θ)        # 板厚
k = ±1                                      # 板体在面的哪一侧（顶面条带所在侧）
```

- 轮廓画在拟合出来的**斜侧面**上，沿水平法向推 `t/cos θ`（上下边保持水平，两侧面间距正好 = t）；
- 沿板方向 d3 重新做一次切片（在 slab 里的点上），得到倾斜板自己的顶边剖面。

### 2.3 删掉斜板的"影子"

倾斜板的可见斜面在俯视图里会被认成一条"矮板"（宽区的斜坡带）。第 8 步末尾（第 477–494 行）把这些影子删掉：对每块倾斜板 A，找顶面中点落在 A 板体里（`−3 < depth < t + 3`，sB 在 A 范围内）且顶高 ≤ A 顶高 + 5 的板 B，删掉 B。更高的板不可能是影子。

S4 里斜板的影子就是那条 `src=slope` 段——它和第 6 步合并出来的宽段其实是同一块板（pair 1-2 off=0.0，厚度 10.71/10.73，合并成一块），所以最后没有多余的影子可删（dups 0）。
