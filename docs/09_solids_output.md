# 09 第 9–10 步：底板轮廓、生成实体、写 STEP

> 读完这一章，你应该能回答：底板轮廓怎么从"看得到的地方"扩成完整的一块？每块板怎么变成实体？STEP 文件怎么不靠 CAD 内核写出来？
> 代码位置：`tools/proto_v2.py` 第 497–514 行（底板轮廓）、第 517–565 行（实体 + STEP），`tools/step_writer.py`。

## 1. 底板轮廓：多数是矩形，补上没扫到的角

底板的边缘常被板、杂物挡住，扫描范围也不一定盖全。做法（第 499–513 行）：

1. `occb = base_vis | raised`：看得到底板的地方 + 所有凸起区（板上站着东西的地方，下面也是底板）。
2. 闭运算（圆盘，半径 6/px）把窄缝糊上，再填洞。
3. 取最大的 8 连通块。
4. 轮廓占**最小外接矩形**的面积 ≥ 85% → 直接用矩形（把没扫到的角落补上）；否则用 `simple_ring` 简化成多边形。

## 2. 每个零件都是一个"棱柱"

```python
solids = []                                  # 第 522 行
```

棱柱 = 一个平面多边形 `ring`（首尾不重复）× 一个拉伸向量 `vec`。四种零件的画法（第 533–562 行）：

| 零件 | ring 画在哪 | vec | 来源 |
|---|---|---|---|
| 竖直立板 | 板的一个侧面：底边 + 顶边剖面 `prof` | `(nrm·w, 0)` 水平推板厚 | 第 8 步的 `prof` |
| 倾斜板 | 拟合出来的斜侧面 | `k·t/cos θ·nh`（斜面的水平法向） | `lean` 的 `prof` |
| 块 | 俯视轮廓（块的底面） | 竖直向上推 `top − bottom` | 第 4 步的 `blobs` |
| 底板 | 底板下表面（俯视轮廓，z = −base_t） | 竖直向上推 `base_t` | 第 9 步的 `base_poly` |

几个细节：

- **立板的多边形**：`[(s0, bottom), (s1, bottom)] + prof 倒序`。底边是平的（z = bottom），顶边是第 8 步的剖面（斜顶、台阶都在）。`dedupe`（第 525–530 行）去掉距离 < 0.5 mm 的重复点。
- **立板的起点**：`base0 = c − nrm·w/2`（中线偏移半个板厚到侧面），所以整个侧面轮廓在正确的平面上。
- **块没有底板的底**：无底板时，取块多边形外接框内全部点 z 的 P1 当底面（第 551–556 行）。
- **全部转回原坐标**：`to_world(Qp) = Qp @ E + o`（第 518–519 行）。STEP 和点云、参考模型直接叠得起来。

每块板一个独立实体，**不做布尔合并**——焊接件本来就是一块块板，也省得处理实体间的缝。

## 3. 写 STEP：纯文本，不依赖 OCCT

`tools/step_writer.py` 直接按 AP214 的文本格式写 `MANIFOLD_SOLID_BREP`（C++ 版的 step_writer 就是它的对照实现）：

- 每个棱柱 = 底面环 `ring` + 顶面环 `ring + vec` + 一圈侧面四边形；
- 写入前 `_clean_ring` 去掉重复点和共线点（退化环直接丢弃）；
- 数字用固定小数位，同一输入跑两次文件**逐字节相同**。

写完把 `LOG["step_solids"]` 记成写进文件的实体数（第 564 行），第 11 步的 `parts.json` 里会有它。

S1 最终输出 3 个实体：

| 实体 | kind | 尺寸 |
|---|---|---|
| plate_00 | strip_thin | t=8.16，L=498.6，顶高 100.4 |
| plate_01 | strip_thin | t=9.63，L=175.5，顶高 80.4 |
| base | base | t=20（默认底板厚） |

对照真相（t=8、500、100；t=10、176、80；底板 20）：都在 0.5 mm 以内。
