# 11 参数说明

> 读完这一章，你应该能回答：程序有哪些可以调的参数？默认值是多少？哪些"常数"其实也是参数，改之前要想清楚什么？
> 命令行参数在 `tools/proto_v2.py` 第 16–22 行，内置常数散在各步。

## 1. 命令行参数

```
python -I tools/proto_v2.py <pcd> <out> [--base-t 20] [--px 1.0] [--mode auto] [--h-min 8] [--w-thin 24] [--lean-min 3]
```

| 参数 | 默认 | 作用 |
|---|---|---|
| `--base-t` | 20.0 | 底板底面看不到时用的默认厚度（mm）。第 2 步能从仿真云量出真实厚度时优先用实测值（`base_t_used`） |
| `--px` | 0 | 高度图像素大小（mm）。0 = 按点密度自动选（第 3 步） |
| `--mode` | `auto` | `base` / `nobase` = 强制指定有没有底板。自动判不准时用（第 13 章记录了几份判不准的云） |
| `--h-min` | 8.0 | 高于底板多少 mm 算"凸起"。有底板时高度图的凸起掩膜用它切 |
| `--w-thin` | 24.0 | 宽于多少 mm 算"宽区"。细条 = 比它窄的凸起区 |
| `--lean-min` | 3.0 | 侧面拟合倾角 ≥ 多少度才按倾斜板建模。设 90 = 全部按竖直板（第 14 章练习 E2 试过） |

## 2. 内置常数（改之前先看第 13 章对应的坑）

这些不是命令行参数，是写死在代码里的"调好的常数"。每个都标了位置：

| 常数 | 值 | 位置 | 干什么 |
|---|---|---|---|
| 切片间距 `BIN` | 5 mm | `proto_v2.py` 第 32 行 | 第 5 步沿轴线的横切间距 |
| 自动像素候选 | 1.0、1.5、2.0、2.5、3.0、4.0 | 第 71 行 | 从小到大试，`ratio ≥ 0.7` 就选 |
| 像素占用率门槛 | 0.7 | 第 71 行 | 再小像素，条带里就全是空洞 |
| 凸起掩膜 | 闭 3×3；补洞 ≤ max(4, 40/px²)；去块 < max(20, 150/px²) | 第 98–102 行 | 高度图去噪 |
| 细条/宽区分界 | `w_thin = 24 mm` | 第 103–104 行 | 开运算圆盘半径 = w_thin/px/2 |
| 判底板 | 面积 ≥ 最大层的 25%；solidity > 0.3；hull_ratio > 0.3；far < 0.03 或 far_below_bottom < 0.03 | `protolib.py` 第 183–190 行附近 | 有底板 ⇔ 全部满足 |
| 层高拾取 | 柱高 ≥ max(30, 平整格 × 1%)；层间距 > 6 mm | `protolib.py` | 第 2 步的水平层 |
| 合并 | 夹角 < 4°；横向 ≤ max(3, 0.5w)；厚度比 ≤ 1.8 + 2；缺口 ≤ 400 mm；缺口 > 15 mm 且底板可见比 > 0.3 不并 | `proto_v2.py` 第 284–294 行 | 第 6 步共线合并 |
| 接头 | 夹角 > 20°；sB 容差 ±10 mm；距离门槛 off + w/2 + **3**（2026-11 起） | 第 318–326 行 | 第 7 步找搭档 |
| 剖面 | 交叉区半宽 hw（公式见第 8 章）；平顶阈值 6 mm；DP 容差 3 mm；下限 bottom + 2 | 第 354、364–368 行 | 第 8 步顶边剖面 |
| 倾斜板 | 门槛见 [08 第 2.1 节](08_profile_lean.md)；rel_dens 用 0.8·sin θ | 第 425–439 行 | 第 8 步判倾斜 |
| 底板轮廓 | 矩形化门槛 0.85；圆盘半径 6/px | 第 501、512 行 | 第 9 步 |
| 实体 | 去重点间距 0.5 mm | 第 529 行 | 第 10 步 |

## 3. 几条原则

- **参数对全部数据统一定，不要为某一份点云单独调**。这些默认值是在 8 份有参考模型 + 34 份无参考 + 7 个合成样例上统一定下来的，对单份点云调参会让别的点云变差（第 1 章末尾有同样的提醒）。
- **先怀疑流程，再怀疑参数**。分数不对时，先按 [10 输出文件详解](10_outputs.md) 看 `segs/fitted/merged/solids` 和调试图，定位是哪一步出的问题，再想是不是常数问题。
- **改常数前先在合成样例上验证**。7 个合成样例每个都带标准答案，改完跑一遍 `tools/synth_bench.py`（见 [12](12_eval_tools.md)），全部 OK 再上真实数据。
- **像素大小和板厚有系统偏差**：点稀的云（点距 1.5 mm 的 S5）量出的板厚偏薄约 1.5 mm，这是方法本身的已知短板（第 13 章），不是调参能解决的，也不用调。
