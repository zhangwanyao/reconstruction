# 大线扫自上而下扫描 · 交线特征逆向建模流程（有底板 / 无底板）

> **说明**：这份是写原型代码之前的设计稿，保留下来是为了看清"当初为什么这样设计"。实现的时候有些细节改了（例如：没有底板的工件，现在也走和有底板一样的高度图流程，不再用平面分割），细节以 [流程总览](02_overview.md) 和之后各篇的逐步详解为准。文中的"现场 168 / 173 / 455"就是其他文档里的 F168 / F173 / F455。

> 目标：面少、实体简单、结果准、每份点云几秒内算完；有底板和没底板的工件都能处理。
> 适用：板件焊接结构（底板 + 立板/筋板、桁架、格构），自上而下扫描，有遮挡。
> 标注：**实测** = 已在 5 份点云上跑过；**估计** = 还没实现，按算法量级估算。

---

## 0. 一句话

**面靠拟合，边靠交线；看不到的面靠厚度和规则补；点云边界只用在自由端。**

---

## 1. 先认清从上往下扫能看到什么

| 几何 | 能不能扫到 | 在建模里干什么 |
|---|---|---|
| 底板上表面 | 大部分能扫到，立板根部的"阴影"扫不到，所以底板会被立板切成好几块 | 基准面，最准 |
| 立板顶面（一条窄条，宽 = 板厚） | 能扫到，除非被更高的盖板挡住 | 定立板的位置和走向（骨架线），以及顶高 |
| 立板侧面 | 只扫到一部分。**实测**侧面点占比：现场 173 只有 1.2%，现场 168 14%，现场 455 19% | 有就用来精修位置，没有也能建 |
| 立板背面和根部、底板下表面 | 基本扫不到 | 不拟合，用"厚度 + 交线"推出来 |
| 被盖板整块挡住的筋板 | 扫不到 | 只能靠设计模型 |

**结论：能可靠扫到的只有"大平面"和"顶面窄条"。** 所以不能指望看清每条边，而是用看得到的面，去算出看不到的边。

## 2. 建模逻辑

### 2.1 模型怎么表示：板 = 平面多边形 × 厚度

焊接件就是十几到几十块板。每块板只需要三样东西：

- 一个参考平面（板的某一面，或者板的中面）
- 平面里的一个轮廓多边形（通常 4～8 个顶点）
- 厚度（以及往哪边长）

拉伸后每块板是一个 6～10 个面的实体。30 块板的工件也就两百来个面。
**不做布尔合并**，每块板是一个独立实体。焊接本来就是一块块板，分开反而更好用，也更快、更不容易出错。

### 2.2 为什么用交线

- 点云里**最不准的是边界上的点**：混合像素、飞点、遮挡、焊缝余高都集中在边上。
- **最准的是面中间的点**：几百上千个点拟合一个平面，噪声被平均掉。**实测**现场点云平面拟合残差的中位数是 0.24～0.41 mm。
- 所以：
  - **棱边 = 两个平面的交线**。立板侧面 ∩ 底板 = 角焊缝；立板侧面 ∩ 另一块立板侧面 = 立焊缝
  - **角点 = 三个平面的交点**
  - **底板轮廓的角点 = 相邻两条边线（平面内的直线）的交点**
- 根部扫不到也没关系：只要侧面上半部分和底板各扫到一部分，交线就能精确算出来。

立板截面：

```
            顶面窄条（能扫到）
            ┌────┐   ← 顶边 = 顶面 ∩ 侧面
            │    │
   侧面A    │    │   侧面B（常扫不到 → 用侧面A 偏移一个板厚）
 (扫到上半) │    │
────────────┘    └────────────  底板上表面（能扫到，根部有阴影）
            ↑    ↑
     焊缝 = 侧面 ∩ 底板（交线：根部没扫到也能算出来）
```

俯视 T 型接头：

```
  ══════════════════════  板B
             ║
             ║  板A
             ║
  板A 的端点 = 板A 中线 ∩ 板B 的近侧面
  两条立焊缝 = 板A 两个侧面 ∩ 板B 近侧面（两条竖直的交线）
```

### 2.3 五条规则（每一步都按这个判断）

1. **看得到的面 → 拟合平面**。只用面中间的点，离交线 5 mm 以内的点不用，避开焊缝和边缘噪声。
2. **看不到的边 → 两个面求交线**。
3. **看不到的面 → 看得到的面偏移一个板厚**。板厚优先用设计值；没有设计值就测顶面窄条的宽度，再取整到标准板厚（4/5/6/8/10/12/14/16/20 …）。
4. **自由端（不和别的板相交的边）→ 才用点云边界**，并标成"推断"。
5. **完全看不到的板 → 不猜**。在报告里列出来，用设计模型补。

两个让结果更稳的做法：

- **方向共享**：互相平行的板（比如所有横筋）共用一个方向，这个方向用所有这些板的点一起求；每块板只单独求自己的位置（偏移量）。这样点少的板也能拟合准。
- **约束拟合**：立板默认垂直于底板，只有测出来明显倾斜（大于 1°）才放开这个约束。

## 3. 总流程：两个入口，一个后端

```
读点云 → 裁掉工作台/ROI → 降采样 → 估法向 → 判断有没有底板
   │
   ├─ 有底板：拟合底板（基准面）→ 工件坐标系 → 取高出底板的点 → 俯视高度图
   │          → 骨架线 → 每条线一块立板 → 每块立板拟合：中面/侧面、顶高、厚度
   │
   └─ 无底板：选基准平面 → 平面分割（法向分组 → 偏移分层 → 连通分块）→ 共面合并
              → 把面组合成板（成对平行面 / 窄条 + 侧面 / 单面 + 厚度）
   │
   ▼  两条线汇合成同一种数据：板件表（每块板的平面、厚度、所属点）+ 相邻关系
交线后端：相邻两面求交线 → 三面求角点 → 修剪成线段 → 围成每块板的轮廓
   → 轮廓 × 厚度 拉伸成实体 → 检查 → 输出 STEP + 焊缝交线表 + 检查报告
```

**两条线只在"怎么把板找出来"上不同；"怎么把板建出来"是同一套。**

## 4. 判断有没有底板

取**最低的大水平面**，同时满足下面两条，就走有底板流程，否则走无底板流程：

1. 它背面（远离相机的一侧）几乎没有点（少于 3%）。
2. 它比较"实"：面积 / 外包凸包面积 > 0.3。底板会被立板和阴影切碎，所以门槛不能定高；而且**同一高度的碎块要先合并成一个平面再算**。

**实测**（探针脚本已在 5 份点云上跑过）：

| 点云 | 最低水平面背后的点 | 填充度 | 判断 | 对不对 |
|---|---|---|---|---|
| 现场 168 | 0% | 0.77 | 有底板 | ✓ |
| 现场 173 | 0% | 0.98 | 有底板 | ✓ |
| 现场 455 | 0% | 0.51（水平面碎成 17 块，合并同一高度后才认出底板） | 有底板 | ✓ |
| SS30 | 0% | 0.99 | 有底板。仿真云的底板上下两面都有点，可以直接测出厚度 10 mm | ✓ |
| SS34 桁架 | **43%** | 0.06 | 无底板 | ✓ |

现场同一个工位的工件类型一般是知道的，也可以直接在配置里指定走哪条线。

## 5. 有底板流程

| 步骤 | 做什么 | 为什么 / 要点 |
|---|---|---|
| H1 读入、裁剪 | 读 PCD（包括压缩格式），按工位 ROI 裁掉工作台和夹具 | 工位固定时，工作台平面只需要**标定一次**，以后直接扣掉 |
| H2 降采样 + 法向 | 体素 3 mm，邻近 12 个点估法向 | 只用来找底板。**实测**现场云 0.2～2.1 s。点很多的大件可以放粗到 5～10 mm |
| H3 找底板 | 法向朝上的点 → 高度直方图 → 最低的大平面 → 用面内点最小二乘精修 → 算平整度 | 平整度 p95 > 1.5 mm 说明底板有变形，后面焊缝改用"立板附近的局部底板面"求交 |
| H4 工件坐标系 | Z = 底板法向（朝相机）；X = 立板的主方向（统计骨架线方向）；原点 = 底板角点 | 之后所有尺寸都在工件坐标系里，能和设计图对上 |
| H5 俯视高度图 | 用**原始点**里高出底板 h_min 以上的点，每个像素取最高值；像素 ≈ 最薄板厚 / 4（1～2 mm） | 只是分格取最大值，几百万点也就零点几秒。像素太粗会把薄板丢掉 |
| H6 骨架线 → 立板 | 二值化 → 骨架化 → 去毛刺 → 折线拆成直线段 → 共线的段合并 | 一条直线段就是一块立板的中线。宽度小于半个最薄板厚的是噪声（之前试过的其他方案在现场 173 出过一块 0.8 mm 宽的"板"）。宽度大于 3 倍板厚的不是立板，按"高出底板的水平板"处理（之前试过的其他方案在现场 455 出过一块 46.5 mm 宽的"板"，很可能就是这种） |
| H7 断开还是遮挡 | 两段共线立板之间有空档时：空档里**扫到了底板** → 真的断开，是两块板；**什么都没扫到** → 是遮挡，连成一块 | 现场最关键的一条遮挡规则。现场 168 的两块长板在接头处就是断开的，要靠这条判断 |
| H8 每块立板拟合 | ① 取中线两侧 t/2 + 3 mm 内的点；② 顶面窄条 → 精修中线；③ 顶面以下的点按在中线左边还是右边分成两组，各拟合一个竖直面（方向固定，只求偏移）；④ 沿板长取顶高剖面，简化成 1～3 段直线 | 某一侧点不够（少于 200 个，或者高度覆盖不到 20 mm）就不用，改成"中线 ± t/2"。偏离中线 ± t/2 超过 2 mm 的侧面点当飞点丢掉 |
| H9 接头和端点 | 在每个端点附近找别的板：**T 型** → 端点 = 本板中线 ∩ 对方近侧面；**L 型** → 看高度图里哪块的顶面在拐角处是连续的，连续的那块盖住另一块；**十字** → 连续的那块贯通，另一块拆成两个 T；**自由端** → 顶面窄条结束的地方，离底板边 10 mm 以内就对齐到底板边 | 绝大多数端点是交线算出来的，只有自由端用点云 |
| H10 立板几何 | 底边 = 侧面 ∩ 底板（就是焊缝）；顶边 = 顶面 ∩ 侧面（或者顶高剖面）；端边 = 对方侧面 → 每块立板得到一个 4～6 条边的轮廓 | |
| H11 底板轮廓 | 底板点 + 立板占的地 + 立板阴影区 → 占据栅格 → 补上遮挡造成的空洞 → 取外轮廓 → 每条边拟合直线 → 相邻两条直线求交得到角点 | **不能用凸包**：之前试过的其他方案用凸包，在现场 168 上把左上角一块没有底板点的三角区也包了进去。真孔的判断：孔里能看到更低的东西（地面或工作台），或者孔是规则的圆或方 |
| H12 生成实体 | 立板：轮廓 × 厚度；底板：轮廓 × 底板厚度（设计值，向下长）；不做布尔合并 | |
| H13 检查、输出 | 见第 9 节 | |

## 6. 无底板流程（以平面为基准分割 → 组合重建）

| 步骤 | 做什么 | 要点 |
|---|---|---|
| P1 读入、裁剪 | 同 H1 | |
| P2 降采样 + 法向 | 体素 ≤ 最薄板厚 / 3（一般 1.5～3 mm），估法向和曲率；曲率大的点（边、焊缝、飞点）不参与分割 | **体素不能粗**。**实测**：SS30 的筋板约 8 mm 厚，体素 3 mm 时能分出竖直面，放到 4.8 mm 后竖直面全部丢失，因为一个邻域把板的两面都包进去了，法向就算乱了 |
| P3 选基准面、定坐标系 | 面积最大的一族平行面（桁架一般是上表面）→ Z；竖直面的主方向 → X | 就是"以平面为基准" |
| P4 平面分割 | ① 按法向分组：水平、竖直（按方位角聚类）、倾斜；② 每组算每个点到原点的偏移，做 1 mm 直方图，一个峰就是一个平面；③ 每个平面里再按连通性分块 | 全是直方图和连通域，不用反复迭代的 RANSAC。**实测** 3～85 万点只要 0.01～2.3 s |
| P5 共面合并 | 同一平面上被遮挡切断的碎块，共用一个平面方程，但各自的区域分开保留 | 平面方程合并（点多更准），区域分开（相邻关系不乱） |
| P6 面组合成板 | 规则 A：两个平行面相距 2～40 mm、投影有重叠 → 一块板，厚度实测；规则 B：窄条水平面（宽 ≈ 板厚）+ 两侧竖直面 → 立板；规则 C：只看到一个面 → 厚度用设计值，往远离相机的方向长；角钢、槽钢 = 共边的几块板 | 薄板多的时候，窄条构件也可以像有底板流程那样用高度图 + 骨架来找，法向只用来分大面，速度更快 |
| P7 相邻关系 | 两块板不平行（夹角 > 20°）、交线离两块板的区域都很近（< t + 5 mm）、沿交线方向有重叠 → 相邻 | 夹角太小的不求交（交线不稳定），改用点云端点 |
| P8 交线后端 | 见第 7 节 | |
| P9 构件底边 | 没有底板时，立着的构件底边扫不到：侧面一直扫到底，就用侧面的最低点；下面有别的水平面，就和它求交；都没有就用设计高度，标"推断" | 这是无底板工件精度最差的地方 |

## 7. 交线后端（两条线共用）

全部是小矩阵运算：

- **平面**：n·x = d（n 是单位法向）。拟合方法：取这些点的重心 c，协方差矩阵最小特征值对应的特征向量就是 n，d = n·c。
- **两面交线**：方向 u = n1 × n2；线上一点 x 解方程组 n1·x = d1、n2·x = d2、u·x = 0。
- **三面交点**：解 n1·x = d1、n2·x = d2、n3·x = d3。三个法向接近共面时（行列式绝对值 < 0.3）不解。
- **交线段的长度**：把两个面上离交线 3 mm 以内的点投影到交线方向上，两个范围取交集（去掉首尾各 1% 的点）。
- **每块板的轮廓**：在板自己的平面里，把交线段（准）和自由边（点云边界拟合的直线）按顺序排好，相邻两条线求交得到顶点，连成多边形。
- **轮廓检查**：多边形不能自交；面积和点云区域相差超过 20%，就退回成简化轮廓并标记出来。

## 8. 遮挡处理规则

| 遮挡情况 | 怎么处理 |
|---|---|
| 立板根部、底板阴影区缺点 | 根部边 = 侧面 ∩ 底板；阴影区按"立板邻域"补成底板，不当成孔 |
| 立板只扫到一个侧面 | 另一侧 = 偏移一个板厚 |
| 立板两侧都没扫到，只有顶面窄条 | 中面 = 窄条中线（竖直约束），两侧 = 中面 ± t/2 |
| 一块板被遮挡断成几段 | 共线，而且空档里没扫到底板 → 合成一块 |
| 端部被遮挡 | 有相邻板 → 端点 = 与相邻板侧面的交点；没有 → 取点云最远端，标"推断" |
| 底板被立板切成很多块 | 同一高度的碎块合成一个平面 |
| 立板被高处的盖板整块挡住 | 扫描里没有就不猜；报告列出"盖板下方未知区"，用设计模型补 |
| 底板下表面、底板厚度 | 用设计值（像 SS30 这种上下两面都有点的才能实测） |

## 9. 检查和输出：结果准不准，要能自己说出来

计划输出：

- `model.step`：每块板一个实体，带名称、厚度、厚度来源（设计值 / 实测）
- `seams.csv`：焊缝就是交线段。记录起点、终点、长度、属于哪两块板、类型（立板-底板角焊 / 立板-立板立焊）、可信度
- `report.json` + `preview.png`

每块板检查三项：

1. 点到面的误差（RMS），超过 1 mm 就标记
2. 每个面被点覆盖的比例，用来区分"实测面"和"推断面"
3. 每个顶点是怎么来的：交线（准）/ 点云边界（±1～3 mm）/ 设计值

全局再查一项：**没被任何板解释的点**（离所有实体都超过 5 mm）聚成团，比最小板尺寸大就报"可能漏板"，并给出位置。之前试过的其他方案在现场 168 漏掉一块长立板，这类问题靠这一项就能自动报出来。

## 10. 计算量

| 步骤 | 用时 | 依据 |
|---|---|---|
| 读入 | 0.01～0.3 s | **实测**（未压缩 PCD）。压缩 PCD 要换成 C 实现的解压，现在的纯 Python 解压要几十秒 |
| 降采样 + 法向 + 平面分割 | 现场 168 0.2 s、173 0.7 s、455 2.1 s；SS34 2.7 s；SS30 4.2 s | **实测** |
| 高度图 + 骨架 | 1～3 s | 估计 |
| 拟合、交线、轮廓 | < 1 s | 估计：只有几十个面，全是小矩阵运算 |
| 生成实体 + STEP | < 1 s | 估计：只做拉伸，不做布尔 |
| **合计目标** | **每份 < 10 s** | 对比：之前试过的其他方案用了 0.5～39 分钟 |

为什么能这么快：

- 只在 3～85 万个降采样点上算，不在几百万个原始点上算法向
- 只用直方图、连通域、骨架、最小二乘和 3×3 方程。不做 Poisson 重建，不做大范围 0.75 mm 深度图，不做反复迭代的 RANSAC，不做布尔合并
- 面确实少：**实测**现场三份点云合并后，水平面只有 2～4 个，竖直面 3～5 个（立板侧面大多没扫全）

## 11. 参数：少，而且都有物理意义

| 参数 | 默认 | 含义 |
|---|---|---|
| 板厚 | 设计值，或标准板厚表 4/5/6/8/10/12/14/16/20 | 看不到的面靠它补 |
| h_min | 10 mm | 高出底板多少才算立板，要大于焊缝余高 |
| 最短板长 | 30 mm | 再短的当噪声 |
| 遮挡最大跨度 | 200 mm | 共线空档小于它，而且空档里没扫到底板，才连起来 |
| 平面容差 | 1.5 mm | 点离面多远以内算这个面上的点 |
| 角度容差 | 3° | 判断平行、共线 |
| 相机方向 | +Z | 决定"背面"在哪一边。5 份点云实测都是 +Z |
| 工作台平面 / ROI | 每个工位标定一次 | |

## 12. 和设计模型结合（下一步，遮挡严重时最稳）

有一种思路是"设计模型匹配 + 局部重建"，可以直接接在这个框架上：

1. **只用平面来配准**：底板平面定 3 个自由度（高度和两个倾角），两块不平行的立板侧面再定 3 个（x、y 和转角）。比拿点云直接做 ICP 快，也更稳。
2. **扫得到的板**：用拟合出的平面替换设计位置（局部重建），交线重新算，焊缝就按实际位置走。
3. **扫不到的板**：保留设计几何。

这样遮挡区不用猜，扫到的地方又是实测的。

## 13. 实施计划

写一个脚本 `plate_rebuild.py`（约 600 行），按上面的步骤拆成函数：读入 → 降采样/法向 → 判底板 → 有底板（高度图、骨架、立板拟合）或无底板（平面分割、组合）→ 交线后端 → 实体和 STEP → 检查。

- SS30 的底板厚度实测 = 10 mm
- SS34 走无底板流程能出模型
